# Study index and evidence map

The [current living report](../README.md) leads with the baseline failure and
the scientific redesign. This index preserves access to all completed studies,
including negative results, calibration qualifications and development controls.
The [full report archived on 7 October 2026](living-research-report-2026-10-07.md)
retains every paragraph, table, figure caption, reference and reproduction
command from the preceding README. Its introduction records the original
README hash and source commit. Historical status statements remain historical.

All commands in linked reports run from the repository root. New or untrusted
policy execution uses the [bounded entry points](foundation-repairs-v1.md#bounded-policy-execution).
Frozen direct APIs and original study runners are for audited trusted policies.
Neither this index nor reproduction commands authorize another search campaign;
all historical allowances are exhausted.

Compact evidence records, source snapshots and figures remain in the checkout.
Before full-bank verification or reproduction, follow the
[release archive and restoration guide](evidence-archives-v1.md). Restore every
published bank with `.venv/bin/python scripts/restore_evidence_v1.py --study all`,
or select one study ID. `--offline` uses verified cached archives. Repository
history remains intact; removing bulky files from the current tree does not
shrink a full historical clone.

## Spatial physical foundation

The [physical foundation report](commons-v3-foundation-v1.md) documents the
implemented mobile-agent engine and both development banks. There are no
institutions or political memberships in these worlds. Development repeats four
seeds across a scarcity grid, fixed sensitivities and four population conditions;
each bank has **56 configurations and 224 episodes**, with zero evolutionary
runs and zero experimental model calls.

At the v2 reference cell, mean restrained/greedy consumption is
**1.200000/0.229769 per agent-tick**. Focal greedy replacement gains no
consumption; its **0.010685** private gain at terminal-wealth weight 0.05 comes
from inventory. Peer consumption falls **0.100769**. Capacity 8 shrinks the
private gain to **0.000252** and eliminates peer consumption losses. Greedy
terminal ecological stock remains **66.70%** of capacity, so low consumption
cannot be equated with collapse of the entire commons. The report retains every
grid cell, null contrast and sensitivity. Four-seed ranges are descriptive,
not confidence intervals.

Ecological qualification and the strong-baseline gate remain open. The next
local control is need-targeted harvest with modest reserves under the same
capacity 80; institutions and enforcement follow later. V3 presently runs
audited built-in policies only. Generated-policy execution has not yet been
integrated with its new action and observation interface.

## Learning and decision controls

Each main world-model study uses a separate case bank and no evolutionary
searches. Independent arenas are the replication units for ecological studies;
members, societies, branches, probe queries and repeated plotting rows are
nested or dependent. All reports retain their complete secondary results and
limitations.

| Study | Design and controls | Supported result | Records and reproduction |
| --- | --- | --- | --- |
| Stationary parameter identification | [Report](world-model-v1.md); 24 independent arenas; frozen prior, private learning and pooled reference with three times the observations | Supplied-equation learning improves prediction. Original pooled spillover coverage was 18/24; this prompted the independent audit. | [Frozen design and evidence](../evidence/world-model-v1/), [gallery](../figures/world-model-v1/README.md), [runner/verifier](../scripts/run_world_model_study.py). |
| Independent calibration audit | [Protocol](world-model-calibration-protocol.md); 128 prior-predictive datasets and 64 ecological arenas; two particle budgets, independent batch reference and frozen-prior negative control | All 192 final references qualify, including one prescribed retry. Bracketed ranges are paired 95% whole-arena bootstrap intervals. Development
gates test computational integrity, ranking sensitivity and consequential
choices; their cases do not enter evaluation estimates. A favorable method
effect is not a gate requirement. The costed-experiment smoke case remains
separate from both banks.

The original calibration runner remains frozen. Use the supplemental verifier
for portable reference-diagnostic comparisons, with the pinned numerical
environment and a new receipt path. A tolerated scalar difference may never
alter a qualification or retry decision. The [repair report](foundation-repairs-v1.md)
records the supported runtime checks, failed older-stack check, bounded execution
and compact [validation records](../evidence/foundation-repairs-v1/).
